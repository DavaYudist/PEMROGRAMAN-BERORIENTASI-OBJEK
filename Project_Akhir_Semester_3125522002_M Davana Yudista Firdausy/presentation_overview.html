Slide 2: Fitur Utama & Batasan Aplikasi

Kemampuan Sistem dan Parameter Batasan Operasional

Fitur Utama Aplikasi:

  • Dual-Launcher Hybrid Architecture: Mendukung antarmuka GUI Native Desktop (JavaFX WebView + Leaflet Map) dan Console CLI interaktif (P13).
  • Live Telemetri GPS Fleet: Memetakan posisi koordinat armada secara interaktif di wilayah Sumenep, Madura beserta telemetri baterai dan suhu kabin VIP.
  • Interactive Bay Lot Management: Visualisasi grid kapasitas parkir 8 hingga 32 slot bay dengan perhitungan rasio okupansi dinamis.
  • Defensive Rental Engine: Pencegahan double-renting, pemblokiran mobil dalam perbaikan, dan kalkulasi tagihan multi-day rental secara polimorfis.
  • Dual-Engine Persistence: Penyimpanan basis data relasional MySQL (JDBC ACID) serta persistensi berkas teks pipe-delimited dengan proteksi dirty-flag.

Batasan Sistem:

  • Kapasitas fisik bay parkir pool depot dibatasi antara 4 hingga 32 slot.
  • Penyimpanan file teks menggunakan delimiter karakter pipe (|), sehingga data input dilarang mengandung karakter tersebut.

Slide 4: Penerapan Pilar OOP, Validasi State, & Persistensi

Integritas Data dan Kebijakan Desain Perangkat Lunak

1. Penerapan Pilar OOP:

  • Enkapsulasi: Seluruh field data berstatus private dengan mutator yang memvalidasi rentang nilai logis.
  • Pewarisan & Polimorfisme: Subclass menurunkan perilaku umum dan meng-override hitungBiayaSewa() serta toJson().

2. Validasi State Defensif (Modul 10):

  • State Invariance: Validasi pra-syarat (ketersediaan, kondisi mesin, durasi, nama) diselesaikan sebelum mutasi state field dilakukan.
  • Penolakan Atomik: Operasi yang gagal melempar eksepsi tanpa meninggalkan efek samping (side-effects) pada objek.

3. Pengelolaan Kumpulan Objek & Persistensi (Modul 11–13):

  • Menggunakan List<Kendaraan>, Map<String, Kendaraan>, dan Set<String> untuk integritas keunikan plat.
  • Pemuatan file defensif membaca seluruh baris ke koleksi sementara sebelum memperbarui state aktif memori.
  • Mekanisme Dirty Flag (berubah) mencegah kehilangan data saat keluar atau memuat ulang.
